### Լաբ 1-ի առաջադրանքը

1. **Class, Random, matrix, set get, private public, constructor**
   - Ստեղծել կլաս, որը կպարունակի $N \times N$ չափերով մատրիցա[cite: 10]
   - Կլասում պահել `private` դաշտեր $N, A$ և $B$ ամբողջ թվերի համար, և նրանց համար ապահովել `{set get}` մեթոդները կարճ գրելաձևով
   - Ստեղծել `private FillMatrix` անունով մեթոդ, որը կլրացնի մատրիցայի արժեքները $[A, B]$ միջակայքից պատահական թվերով
   - Ստեղծել `public ShowMatrix` մեթոդը, որը ցույց կարտածի մատրիցայի պարունակությունը[cite: 10]
   - Ստեղծել մեթոդ, որը կվերադարձնի մատրիցայի կենտ թվերի քանակը[cite: 10]
   - Պարամետրիզացված կոնստրուկտորով տեղադրել $N, A$ և $B$ դաշտերի արժեքները, որից հետո կանչել `FillMatrix` մեթոդը[cite: 10]
   - Ցույց տալ կլասի ֆունկցիոնալությունը `Main()` մեթոդում[cite: 10]

### Լաբ 2-ի առաջադրանքը

2. **Method overloading, default parameters**
   - Ստեղծել `static ToMultiplicate` մեթոդ (3 օրինակով), որը կընդունի $x$ և $N$ փոփոխականները
   - $N$-ը կունենա ըստ լռելյայն (`default`) արժեք 2, կլինի `int` տիպի
   - Իսկ $x$-ը կլինի երեք տարբերակով՝ `int`, `double` և `string`
   - Ֆունկցիան պիտի վերադարձնի $N$ հատ $x$-երի գումարը *(հատուկ այսպես գրվեց, որ string-ի դեպքն էլ հասկանալի լինի)*[cite: 10]
   - Թեստավորել `overloading`-ի աշխատանքը `Main()` մեթոդում

### Լաբ 3-ի առաջադրանքը

3. **String, Formatting, Enum, Switch**
   - Ստեղծել `Movie.cs` կլասը, որը կպարունակի՝ [ֆիլմի համարը, ֆիլմի անունը, տարեթիվը, ֆիլմի ժանրը, դիտումների քանակը, լայքերի քանակը]
   - Ֆիլմի ժանրի համար ստեղծել `enum` (5 տարբերակ պարունակող, ըստ ձեր հայեցողությամբ)
   - Մուտքագրումը կատարել Console-ից `ReadLine()` մեթոդով, ժանրը գրել որպես 1-ից 5 թիվ, որից հետո ինֆորմացիան տարանջատել (`split`) և տեղավորել կլասի դաշտերում[cite: 10]
   - Ստեղծել նաև մեթոդ, որը կհաշվի ֆիլմի ռեյտինգը հետևյալ բանաձևով՝ `SQRT(Likes ^ 2 / Views)` (`double` տիպի)[cite: 10]
   - `Movie.cs` կլասի համար `override` անել `ToString()` մեթոդը, որը ցույց կտա կլասի պարունակությունը հետևյալ կերպ.
     - Ֆիլմի համարը, `{4 տառաչափ, կցել աջ}`
     - Ֆիլմի անունը, `{15 տառաչափ, կցել ձախ}`
     - Տարեթիվը, `{8 տառաչափ, կցել ձախ և փակագծերի մեջ, օր․՝ "(2011)"}`
     - Ֆիլմի ժանրը, `{12 տառաչափ, տեքստային, կցել ձախ}`
     - Ռեյտինգը, `{8 տառաչափ, ստորակետից հետո 1000-րդական ճշտությամբ, անպայման ցույց տա նաև եթե զրոներ են}`
   - Ցույց տալ կլասի ֆունկցիոնալությունը `Main()` մեթոդում. ծրագիրը սկզբում կընդունի քանակը (օրինակ՝ 7) և հետո ցիկլով կընդունի 7 հատ ֆիլմի տվյալներ, այնուհետև ցիկլով ցույց կտա ֆորմատավորված տեսքով[cite: 10]
   - Որպեսզի ավելորդ չբարդացնեք, բոլոր մեմբերները և մեթոդները ստեղծել `public`

### Լաբ 4-ի առաջադրանքը

4. **using in, out, ref, params, and parameters by default values**
   - Ստեղծել `static A()`, `B()`, `C()` մեթոդները՝ համապատասխանաբար `in`, `out`, `ref` մոդիֆիկատորները փորձարկելու համար
